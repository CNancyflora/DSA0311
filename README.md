## 📂 Section Breakdown

### 1. Unit-Wise Assessments (`Unit-1` to `Unit-5`)
Each unit contains three designated assessment folders corresponding to periodic assessments:
- **`Assessment-1`**: First internal evaluation / quiz / submission
- **`Assessment-2`**: Second internal evaluation / problem-solving tasks
- **`Assessment-3`**: Comprehensive unit evaluation / project component

*Existing Submissions:*
- [`Unit-1/Assessment-1/`](Unit-1/Assessment-1/): Contains initial assessment submission (`192324117_NLP_at1.pdf`).

---

### 2. Capstone Project (`Capstone-Project/`)
Dedicated workspace for the final end-to-end NLP capstone implementation:
- **`PPT/`**: Presentation slide decks for project reviews and viva voce.
- **`Reports/`**: Documentation, synopsis, SRS, literature survey, and final project report.
- **`Datasets/`**: Training, validation, and testing corpora / datasets.
- **`Source-Code/`**: Full implementation, preprocessing scripts, model training notebooks, and inference pipelines.

---

### 3. Assignments (`Assignments/`)
Contains individual coursework assignments:
- **`Assignment-1/`**: Foundational linguistics, regular expressions, and corpus analysis.
- **`Assignment-2/`**: Morphological analysis, POS tagging, and language models.
- **`Assignment-3/`**: Parsing techniques, semantic analysis, and word vectors.
- **`Assignment-4/`**: Advanced deep learning architectures and transformers in NLP.

---

### 4. Certificates (`Certificates/`)
Archive for NPTEL, Coursera, academic workshops, hackathons, and seminar certificates related to Natural Language Processing and Machine Learning.

---

### 5. Laboratory Experiments (`Experiment/`)
Laboratory practicals are documented using a standardized 8-section report structure:
1. **Aim**: Clear statement of the experiment purpose.
2. **Objective**: Specific learning and technical objectives.
3. **Algorithm**: Step-by-step logical workflow.
4. **Flowchart**: Diagrammatic representation of execution.
5. **Code**: Clean, commented source code or reference link.
6. **Output**: Execution logs and screenshots.
7. **Result**: Analytical summary of observed outcomes.
8. **Conclusion**: Technical takeaway and understanding gained.

## 🧭 Navigation & Guidelines

- **Standardized Naming**: All directories follow kebab-case (`Unit-X`, `Assessment-Y`, `Experiment-Z`) for strict cross-platform compatibility across Windows, Linux, and GitHub.
- **Version Tracking**: Empty directories are initialized with `.gitkeep` so they remain tracked in Git.
- **Preserved History**: All prior assessment materials and commit histories remain intact.
